# Changes since v0.14.0

## :warning: Breaking Changes

- Remove HardwareDetails from BaremetalHost v1beta1 status (#3815)
- v1beta1: remove the md5 checksum type (#3785)
- Remove delete/update constraints on HNA when still referenced by BMH (#3769)
- Stop using deprecated iDRAC subinterfaces (requires Ironic 26.1) (#3539)
- Drop support for non-HFS firmware settings (#3511)
- Remove deprecated firmware fields from v1beta1 (#3846)
- Rename BareMetalHost online field to poweredOn (#3844)
- Rename root device hints in BareMetalHost v1beta1 (#3823)
- Remove HardwareProfile from BareMetalHost v1beta1 (#3802)

:rotating_light: This is a BETA RELEASE. Use it only for testing purposes.
If you find any bugs, file an [issue](https://github.com/metal3-io/baremetal-operator/issues/new/).
